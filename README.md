# ConeWorld
A Godot 3 project: a demo of a turn-based RPG puzzle game.

<img width="480" height="319" alt="coneworldpreview" src="https://github.com/user-attachments/assets/316f097d-f19e-423f-b1e9-8bfa110826d1" />

A turn-based CPG (cone-playing game) in which you void slimes, catch butterflies, and wander the coneworld. The demo contains five levels (in the "demo" directory) and the "Project_files" directory contains all source files.

## Playing the demo

<img width="480" height="319" alt="coneworldpreview2" src="https://github.com/user-attachments/assets/9e2f34f8-6638-462c-ade6-a36779bf36c2" />

- Step 1: duplicate the ConeWorldDemo directory. (The source files in the Project_files directory are *not needed*.)
- Step 2: open the html file in a browser of your choice.

That's it! If this doesn't work, the most likely issue is that your browser has security settings against fetching local files. In that case, you can also try playing the demo [through my website](https://sfushidahardy.github.io/misc/ConeWorldDemo/coneworld.html).
